# 아파트 매물 리포트

네이버 부동산 공개 매물과 국토교통부 실거래가를 매일 수집해 만든 리포트입니다.
관심 단지의 호가 변동(신규·하향·상향·소멸)과 실거래 대비 괴리를 추적합니다.

- 최신 리포트: [index.html](./index.html)
- 갱신: 매일 07:30 (자동)

## 주의

- **호가는 체결가가 아닙니다.** 실제 거래는 조정될 수 있습니다.
- 같은 물건이 여러 부동산에 등록되면 중복으로 잡힙니다. 리포트는 `동·층·타입·향`이
  같으면 한 물건으로 묶어 표시합니다.
- 실거래는 네이버 제공 데이터이며 국토교통부 원자료와 시점 차이가 있을 수 있습니다.
- 본 자료는 정보 정리용이며 투자 권유가 아닙니다.
